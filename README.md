Assignment 1 - Hello World: GitHub and d3  
===

GitHub pages link: https://shuying-afk.github.io/a1-shuying-afk-shuying-zhao/ 

This code creates a mountainous scenery with a lone snowman on a grassy field. The mountains were created with numerous polygons. The house was consisted of rectangles, circles, and lines. The snowman with tons of circles. I started this code from scratch, using Claude in the beginning to simplify and understand the documentation and capabilities of d3.
